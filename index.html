Project Overview

The project uses one narrowed PHMSA dataset: hazardous liquid pipeline accidents from January 2010 to present. The analysis looks at accident patterns by year, state, commodity, cause, release volume, injuries, fatalities, and cost. It also creates a binary target called high_cost_incident so the project includes both descriptive analysis and a basic predictive step.

  • The scope was narrowed to one accident system so the project stayed realistic and easier to explain.
  • The main cost proxy used in the project is the PHMSA PRPTY field.
  • The final modeling goal is to identify which accident characteristics are more associated with higher-cost outcomes.

Why This Dataset Was the Best Final Choice

This hazardous liquid dataset was a better fit than trying to combine multiple PHMSA systems. It has clearer release and cost fields, it fits the safety-and-risk focus of the project, and it avoids a much messier merge process.

Project Method

Data preparation

  • Loaded the PHMSA hazardous liquid text file with delimiter detection and encoding fallback.
  • Cleaned column names and mapped the working fields used in the analysis.
  • Converted release, injuries, fatalities, and cost fields to numeric form.
  • Created high_cost_incident = 1 when total cost was above the 75th percentile.

Analysis and modeling

  • Generated charts and summary tables for year, state, cause, commodity, and cost patterns.
  • Compared logistic regression, decision tree, and random forest models.
  • Used an 80/20 train-test split with one-hot encoding for categorical features.
  • Evaluated model performance with accuracy, precision, recall, F1-score, and confusion matrix.

Chart Walkthrough

Each chart below includes a short explanation of what it shows and what the main takeaway is.

Hazardous Liquid Accidents by Year

What this chart shows

This chart shows the number of hazardous liquid accidents reported each year in the PHMSA file.

Key takeaway

Accident counts rose through the mid-2010s and generally moved lower after 2019. The latest year should be treated carefully because it is only a partial year in the current file.

Top States by Accident Count

What this chart shows

The chart ranks the states with the highest number of hazardous liquid accidents. Texas stands far above the rest with 2,420 reported accidents.

Key takeaway

The data is not evenly spread across states. A small number of states account for a large share of the recorded accidents, which matters when interpreting broader trends.

Incident Count by Cause

What this chart shows

This chart compares the most common cause categories in the file. Equipment failure is the largest category, followed by corrosion failure and incorrect operation.

Key takeaway

The most frequent cause is not always the most expensive cause. Count and severity need to be read separately.

Incident Count by Commodity

What this chart shows

This chart compares the main commodity categories involved in accidents. Crude oil is the dominant commodity in the file.

Key takeaway

Commodity mix matters because it shapes both accident frequency and the kinds of release and cleanup costs seen later in the project.

Total Cost Distribution

What this chart shows

The cost distribution is shown on a log scale because the raw values are extremely skewed.

Key takeaway

Most accidents are much lower cost than the biggest events. A small number of very large accidents heavily shape the cost picture, which is why median cost is often more useful than mean cost.

Median Cost by Cause

What this chart shows

This chart compares median cost by cause category instead of simple incident counts.

Key takeaway

Excavation damage, material failure of pipe or weld, and other outside force damage stand out as costlier categories on a typical event basis. This is one of the clearest descriptive findings in the project.

High-Cost Incidents by Cause

What this chart shows

This chart focuses only on the accidents labeled as high cost under the project threshold.

Key takeaway

Corrosion failure and equipment failure account for many high-cost events, even though their typical cost levels differ. This helps explain why the project used both descriptive charts and a classification model.

High-Cost Target and Modeling Results

The project labels an accident as high cost when the cost proxy is above $148,646. That puts about 25.0% of the accidents in the positive class.

Interpretation

What mattered most in the model

Release volume was the strongest feature by a wide margin. Cause categories such as equipment failure, material failure of pipe or weld, corrosion failure, and excavation damage also carried useful signal.

In plain terms, the model leaned more on severity and cause information than on location alone.

Main Takeaways

  • Texas dominated the accident count in the file.
  • Equipment failure was the most common cause category.
  • Corrosion failure produced many high-cost events.
  • Crude oil was the most common commodity category.
  • Release volume was the strongest model feature, which suggests severity variables matter more than simple location alone.

Limitations and Future Work

Limitations

  • The project uses one PHMSA hazardous liquid dataset and does not merge multiple systems.
  • The cost field is heavily skewed by a small number of very large events.
  • The model uses a modest feature set and should be treated as a baseline.

Future work

  • Add geospatial mapping and operator-level analysis.
  • Test alternative cost or severity definitions.
  • Try additional models and a dashboard layer.
